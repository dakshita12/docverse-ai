# DocVerse AI

An AI-powered study workspace that helps students organize, search, and interact with their study materials using Retrieval-Augmented Generation (RAG).

## Features (Planned)

- Document Upload & Management
- PDF, DOCX & PPTX Support
- OCR for Scanned Documents
- AI Chat with Documents
- AI Summaries
- Smart Notes
- Flashcards
- MCQ Generation
- Important Question Generation
- Semantic Search

## Tech Stack

- Python
- Streamlit
- LangChain
- Gemini API
- ChromaDB
- Sentence Transformers
- SQLite
